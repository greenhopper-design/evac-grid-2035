# 조력 구역 그리드 · 2035 서울 피난 시뮬레이션

AI도시건축디자인론 중간고사(2035 미션 카드 해커톤, 2026.11.03) 제출물.

카드: ① 기둥 그리드 × ② 사람의 흐름 × ③ 에이전트 시뮬레이션

- `index.html`: 실험 결과와 설계 제안
- `sim.html`: 브라우저 피난 시뮬레이터 (장소 3곳, 기둥 유형 A~E, 직원 조력 시나리오 S1~S4)
- `slides.html`: 발표 슬라이드 (← → 키 또는 클릭으로 넘김)

모델: 사회력 모델(Helbing·Farkas·Vicsek 2000) + 출구 거리장, 사람 유형·직원 행동은 Lim·Lee·Hwang(2023, Buildings 13(2):400) 값.
평면은 공개 구내도·층별 배치도를 따라 그린 개략 평면이며, 수치는 유형 비교용(RSET 아님)이다.
